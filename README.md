## Getting Started

### Prerequisites

- Node.js 18+ and npm/yarn/pnpm

### Installation

1. Clone the repository
   git clone https://github.com/tnex0734-ops/PORTFOLIO.git
   cd PORTFOLIO

2. Install dependencies
   npm install

3. Start the development server
   npm run dev

4. Open http://localhost:3000 in your browser.
